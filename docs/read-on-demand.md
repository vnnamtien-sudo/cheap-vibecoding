# 按需读取，减少重复上下文

[English](read-on-demand.en.md) · [README](../README.md)

派单精确到目标函数和一份合成样本，例如 `src/total.py: sum_values`，输入 `[2, 5]`，预期 `7`。路径只是例子，由项目实际目录决定。交付边界、不可改规则和验收命令一并写明，不让模型先通读整个项目。

1. 先搜索目标符号和调用位置，记下行号。
2. 先读目标函数附近，单次不超过 gate.config.json 的 readLimitLines。
3. 证据不足时再读调用方、类型定义或一份测试；每次写明读取目的。
4. 交接只传派单、差异、自检回执和单份样本，轻验收开同账号的新会话。

文本模板无需运行环境，见 [AGENTS 骨架](../templates/AGENTS.md)、[派单](../templates/dispatch/task.md)、[交接](../templates/dispatch/handoff.md)。Claude 可选读取钩子读取同一份配置，其他平台靠规矩约束；钩子不是 shell 命令沙箱，不能识别任意命令的全部读取行为。

遇到大文件先定位再分段，禁止整份输出。生成文件与二进制文件优先查来源，不把无法分析当作已通过。效果因电脑配置、模型、项目而异。
