# 调整本地配置

[← 返回 README](../README.md)

初始化会在目标项目根目录生成 gate.config.json。只填写你已确认、并且本项目确实要用的字段；不要把本机路径、会话记录或价格猜测提交到仓库。

- 规则、自检和定向测试可以分别启用。单独复制规则文件不需要 Python 或其他运行时。
- 默认 testCommand 指向项目内生成的定向测试入口。只有测试映射不适合本项目时才修改它。
- 使用 token 或阶段统计时，先在本机配置你确认的数据来源和价格；默认不读取个人会话目录，也不猜价。
- 可选 Git 提交钩子不会覆盖已有钩子。安装方法和参数见 gate-config.md。
- 配置改完后，可从工具仓库运行 python3 tools/self-check.py --root <项目> --config。

队列容量、健康检查冷静期和多会话分工属于高级调优；单人单会话不需要修改，见[高级配置](advanced.md)。
