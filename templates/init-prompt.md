# 给新项目的初始化提示词

这是一个人一个账号的开发方案；本提示词无需安装运行环境。

请把本项目接入省 Token 与防返工流程：
1. 先列扩展名、顶层目录、包管理和测试入口；先搜索再分段读取，每次不超过 60 行。
2. 已有初稿时读取根目录 gate.config.json；否则按 gate.config.example.json 的字段生成初稿。脚本可选：从工具仓库运行 `python3 tools/init.py --root <项目目录>`。
3. 按真实目录调整 layers；允许关系从实际 import 推导，冲突留待确认。
4. 按项目可执行的测试填写 testCommand 和 testMappings；命令用参数数组，{files} 单独占一项，不拼 shell。
5. 类型检查和数据比对可留空；留空必须在回执中显示跳过，不能当作已验证。
6. 设置 maxFileLines、maxFunctionLines、bannedPatterns、readLimitLines。禁用正则需带说明。
7. roles 按四个平台保留主写、轻验收、最终验收、只读核对；只填核实可用的型号。
8. 日常写作与核对为 high；算钱算账、大重构、发布前的最终验收为 xhigh。平台不支持时说明能力缺口。
9. 轻验收在同一账号的新会话进行，不带前文。额度紧时轻活用轻型号、验收攒批、不急的暂停。
10. 用一个合成样本证明改动相关测试能选中；用失败样本证明本地自检会阻断。

输出：配置初稿、证据定位、待确认项、一个具体函数的首张派单。不读取真实私密样本，不执行项目代码来猜测架构。
